Painel Administrativo

Configurações da Página

Edite aqui todos os links, textos e integrações da sua Link da Bio. As alterações são salvas automaticamente.

📌 Como usar este painel

  1. Preencha os campos abaixo com seus links e informações reais.
  2. Clique em "Salvar Configurações" ao final.
  3. As alterações aparecerão automaticamente na sua página principal.
  4. Para dados persistentes entre dispositivos, cole os valores diretamente no arquivo link-bio.html no objeto CONFIG.
1 Identidade da Marca
Logo, nome e textos principais da página.
Envie o arquivo para a pasta assets/ ou cole uma URL externa.
2 WhatsApp da Equipe
Número que receberá os contatos e mensagem automática pré-preenchida.
Só dígitos, sem espaços ou símbolos.
3 Links dos Botões
URLs de destino de cada botão da página.
4 Presente Gratuito
Arquivo PDF que será entregue automaticamente após o envio do formulário.
Envie o arquivo para a pasta assets/ e cole aqui o caminho.
5 Integrações & Automação
Google Sheets, tracking e códigos externos.
Veja o tutorial abaixo para gerar essa URL.

🔗 Como integrar com o Google Sheets

  1. Crie uma planilha nova no Google Sheets.
  2. Vá em Extensões → Apps Script.
  3. Cole o código abaixo e salve: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([new Date(), data.nome, data.whatsapp, data.email, data.origem]);
  return ContentService.createTextOutput(JSON.stringify({success:true}));
}
  4. Clique em Implantar → Nova implantação → Web app.
  5. Executar como: Eu. Quem tem acesso: Qualquer pessoa.
  6. Copie a URL gerada e cole no campo "URL do Google Apps Script" acima.
✓ Configurações salvas com sucesso!
